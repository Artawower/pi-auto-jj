Automatic [[https://github.com/martinvonz/jj][jj]] revision management for [[https://pi.dev][pi]] coding agent.

* What it does

- 🛡️ /Guards file edits/ — blocks =write= / =edit= when the current jj revision is sealed
- 🏷️ /Auto-describes/ — sets revision description from your prompt when work finishes on an empty revision
- 🤖 /LLM decides/ — blocked edits show clear instructions, the model chooses =jj new= or =jj desc=

* Install

#+BEGIN_SRC bash
pi install npm:pi-jj-auto
#+END_SRC

Or from source:

#+BEGIN_SRC bash
pi install https://github.com/Artawower/pi-auto-jj.git
#+END_SRC

* How it works

1. You send a prompt
2. LLM tries to edit a file
3. Extension checks the current jj revision (description × diff state):
   - *Empty description, no diff* → pass through (fresh revision, work freely)
   - *Empty description, has diff* → block: run =jj describe -m= or =jj new -m= first
   - *Has description, no diff* → pass through (clean slate for new work)
   - *Has description, has diff* → block: same task? =jj describe -m=, new task? =jj new -m=
4. LLM runs the right jj command, retries the edit
5. When done, warns if the revision still has no description

* Configuration

Global: =~/.pi/agent/pi-jj-auto.json= \\
Project: =.pi/pi-jj-auto.json=

#+BEGIN_SRC json
{
  "enabled": true,
  "blockOnMismatch": true,
  "autoDescribe": true,
  "maxPromptLength": 72
}
#+END_SRC

| Field              | Type    | Default | Description                                      |
|--------------------+---------+---------+--------------------------------------------------|
| =enabled=          | boolean | =true=  | Enable/disable                                    |
| =blockOnMismatch=  | boolean | =true=  | Block edits or just notify                        |
| =autoDescribe=     | boolean | =true=  | Warn when revision has diff but no description     |
| =maxPromptLength=  | number  | =72=    | Max task length in guard messages                 |

* Debug

#+begin_src bash
